# 后台功能用法

本章逐一介绍管理面板的七个模块。登录入口为 `/zexo/admin/login`，登录成功后进入仪表盘。

## 登录

- 访问 `https://<你的域名>/zexo/admin/login`，输入用户名与密码；
- 支持多用户：环境变量中用逗号分隔多组用户名 / 密码；
- 登录态通过 Cookie 保存（`username` / `password` 的 MD5 值），退出登录请点击右上角头像 → 退出；
- 若 `zexo_captcha` 为 `True`，登录前会弹出滑块验证码（验证图由 `/zexo/api/captchaimg` 提供）。

::: tip 登录后立刻被踢回登录页？
这是最常见的新手问题，通常是环境变量没配对。排查方法见 [常见问题](/guide/faq#登录后立刻被跳转回登录页)。
:::

## 主页

仪表盘主页展示四张卡片：

- **总文档数**：文章仓库 `source/_posts` 中的文件总数（含子目录），点击「前往管理」跳转书写页；
- **总图片数**：图片仓库中的文件总数，点击「前往管理」跳转图片管理页；
- **当前版本**：显示 Worker 脚本版本号（如 `Zexo@1.5`），**点击卡片可检查更新**；
- **Github**：快速跳转你的文章仓库。

## 书写

「书写」页是 Zexo 的核心，一个功能完备的 Markdown 编辑器。

### 编辑器工具栏

工具栏与 Modrinth 的编辑器一一对应，分为四组：

| 分组 | 按钮 |
| --- | --- |
| 标题 | H1 / H2 / H3 |
| 样式 | 加粗、斜体、删除线、代码块、折叠剧透 |
| 列表 | 无序列表、有序列表、引用 |
| 组件 | 插入链接、插入图片（上传 / 外链）、插入 YouTube 视频、OwO 表情 |

支持的快捷键：`Ctrl+B` 加粗、`Ctrl+I` 斜体、`Ctrl+S` 删除线、`Ctrl+E` 代码块、`Ctrl+Shift+7` 有序列表、`Ctrl+Shift+.` 引用。回车时会自动延续列表与代码块结构，与 Modrinth 的输入增强一致。

### 图片上传

三种方式任选：

- **粘贴上传**：截屏后直接在编辑器里 `Ctrl+V`，自动上传到图床并插入 Markdown；
- **按钮上传**：点击工具栏的图片按钮，可选择上传文件或填写外链；
- **OwO 表情**：表情以图片形式插入。

上传走 `/zexo/admin/api/addimage/<扩展名>`，成功后返回 jsDelivr CDN 链接。

### 预览与高亮

编辑器右上角的「预览」开关实时渲染 Markdown：输出经过 DOMPurify 白名单过滤，代码块按配置的 `zexo_highlight_style` 主题高亮，图片自动补懒加载。

### 自动备份

工具栏的时钟按钮控制自动备份：开启后内容按固定间隔存入浏览器 `localStorage`，误触关闭也不会丢稿。刷新页面会自动恢复上次内容。

### 导入本地文件

工具栏的导入按钮（或「获取文章」旁的文件选择）可以把本地 `.md` 文件读入编辑器，适合迁移旧文章。

### 发布相关按钮

页面顶部的操作区：

| 按钮 | 作用 |
| --- | --- |
| 文件选择 | 下拉框列出已有文章，支持输入过滤（可编辑下拉框）；发布时作为目标文件名 |
| 获取文章 | 把选中文件的内容读入编辑器 |
| 获取艹稿 | 把选中草稿读入编辑器 |
| 徒手清索引 | 清除文章 / 草稿列表索引缓存 |
| 发布文件 | 把编辑器内容发布到 `source/_posts/<文件名>` |
| 发布艹稿 | 把编辑器内容发布到 `source/_drafts/<文件名>` |

::: tip 文件名
发布时的文件名取自「文件选择」框，不带 `.md` 后缀。下拉框是**可编辑**的：直接输入新名字即可发布新文章。
:::

## 说说

「说说」页是一个轻量的朋友圈 / 微博：

- 在编辑器中书写，点击 Upload 发布到 KV；
- 已发布的说说显示在下方，支持**删除**与**隐藏 / 显示**（隐藏后不在博客前端展示）；
- 说说通过 `/zexo/api/getzexotalk` 接口供博客前端读取，嵌入方法见 [博客集成](/guide/blog-integration)。

## 文档管理

「文档管理」页列出文章仓库中的全部文件，包括：

- **已发布**文章（`source/_posts`）与**未发布**草稿（`source/_drafts`），状态列有明确标识；
- 每行显示名称、大小、发布状态，以及 CDN 链接、原始地址、Github 地址；
- 顶部搜索框实时过滤，底部自动分页（每页条数由 `zexo_page_limit` 决定）；
- 点击「删除」经二次确认后从 GitHub 仓库移除，并自动清理索引缓存。

## 图片管理

「图片管理」页列出图片仓库中的全部文件：

- 缩略图懒加载，点击弹出 swipebox 灯箱大图预览；
- 每行提供 CDN 链接、原始地址、Github 地址与删除操作；
- CDN 链接格式为 `https://cdn.jsdelivr.net/gh/<用户>/<仓库>@<分支><路径><文件名>`，可直接复制到博客中使用。

## 工具

「工具」页集中了三个不常用但很重要的操作：

### 从 Artitalk 中导入

把 LeanCloud 导出的 Artitalk 数据（每行一条 JSON）粘贴进弹窗，点击确认后批量导入为 Zexo 说说，时间与头像都会保留。

### 触发 Pages 部署

点击后 POST 配置中的 `zexo_deploy_hook_url`，触发 Cloudflare Pages 重新构建你的博客。适合改了仓库但自动构建没跟上，或者想强制刷新缓存的场景。未配置部署钩子时点击会提示失败。

### 销毁配置

清空 `zexo_config`，让面板回到未安装状态。**高危操作**，连续三次确认才会执行。

## 设置

「设置」页以表格展示 `zexo_config` 中的全部键值：

- **修改**：点击「修改」输入新值；
- **删除**：点击「删除」移除某个键（同样有三次确认）；
- **新增**：表格底部「新增一项」可添加自定义键值，例如上面提到的 `zexo_plugin_js`。

## 检查更新

主页的「当前版本」卡片就是更新入口：

- 点击后从 GitHub 拉取 `update.js`，与当前 `zexo_ver` 比较；
- 存在新版本时弹出更新确认，点击「是」通过 Cloudflare API 用 `main` 分支的脚本热更新你的 Worker；
- 更新过程约几秒，成功后页面自动刷新；
- 想要尝试实验版本，可在「工具」或更新弹窗中选择小白鼠更新（拉取 `dist` 分支的压缩产物）。

::: warning
一键更新依赖配置中的 Cloudflare Global API Key、账户邮箱、账户 ID 与 Workers 名称，任缺一项都会更新失败。Dashboard 粘贴部署的用户请手动更新。
:::
